# Componentes externos

O projeto usa HT Demucs (MIT), conversão demucs-onnx (MIT), ONNX Runtime Web (MIT), TensorFlow.js (Apache 2.0) e Basic Pitch (Apache 2.0). As licenças completas dos pacotes instalados são preservadas pelo npm. O bundle mantém os avisos de licença dos módulos.

A implementação de overlap-add foi orientada pela documentação do projeto demucs-onnx, com adaptação para cinco faixas mono.
